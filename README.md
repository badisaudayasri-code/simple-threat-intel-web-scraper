

## Project Description
This project demonstrates a simple Threat Intelligence collection system using Python.  
It simulates the process of gathering cybersecurity threat-related information such as phishing attacks, malware, ransomware, and data breaches.

Due to network and SSL restrictions in mobile-based Python execution environments, the project uses predefined real-world cybersecurity threat headlines. This approach ensures error-free execution while still effectively demonstrating the concept of threat intelligence collection and analysis.

## Objectives
- Understand the basics of Threat Intelligence
- Demonstrate ethical data collection techniques
- Simulate real-world cyber threat monitoring
- Practice Python programming for cybersecurity applications

## Features
- Displays latest cybersecurity threat headlines
- No external libraries required
- Works in mobile and offline environments
- Simple, readable, and beginner-friendly code
- Error-free execution without internet dependency

## Technologies Used
- Python 3
- Standard Python libraries only

## How to Run
1. Open any Python compiler or mobile coding app
2. Create a file named `threat_intel_scraper.py`
3. Copy and paste the provided Python code
4. Run the program
